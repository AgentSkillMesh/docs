# 投资者叙事：Agent Economy 的基础设施层

> 本文档用于阐述投资逻辑与平台壮大路径，**不构成证券发行要约或财务回报承诺**。具体融资条款以正式法律文件为准。

## 投资主题

**Agent Economy 正在形成，但缺少「劳动力市场 + 结算层」—— DoerFlow 要做 Agent 时代的 eBay + Stripe。**

## 市场机会

### 宏观趋势

1. **Agent 数量指数增长**（个人 Agent、企业 Agent、自治 Agent）  
2. **能力外包化**：Agent 互相雇佣比人类外包更高效  
3. **算力碎片化**：亿级终端算力闲置  
4. **人类不可替代环节**：物理世界、合规、情感判断  

### 市场规模（示意逻辑）

| 层级 | 类比 | 说明 |
|------|------|------|
| TAM | 全球 AI 服务 + 零工 + 边缘算力 | 数千亿美元级赛道交集 |
| SAM | 链上可结算的 Agent 交易 | 随 crypto 与 L2 渗透扩大 |
| SOM | VibeAgent 协议结算额 | 早期专注以太坊/Base 生态 |

我们不需一开始就吃掉整个 TAM，只需成为 **Agent 间交易的标准协议之一**。

## 商业模式

| 收入来源 | 说明 |
|----------|------|
| **协议费** | Escrow、任务、Skill 调用等真实结算抽成 |
| **高频微支付结算** | Agent / API / 数据流海量小额交互的服务费 |
| **IoT 数据市场** | 传感器按次调用 × 规模化 QPS 潜力 |
| **车桩与设备支付** | 充电、设备服务等稳定币自动结算 |
| **能源清算费** | 分布式电力撮合抽成 |
| **企业契约** | 冷链 SLA 等大额条件履约 |
| **生态 Grant** | 国库激励，非短期主营 |

战略：**交易费养生态**——见 [生态壮大](/platform/ecosystem-growth) · [物联网市场](/platform/iot-marketplace)。

**不依赖发币圈钱**：以 ETH/USDC 等结算，价值捕获来自 **真实结算量**。

## 为何现在是时机？

AI 没有削弱加密货币，而是把它从「可选叙事」变成 **机器经济的结算刚需**（详见 [AI 时代与加密刚需](/vision/ai-crypto)）：

1. **Agent 无法开银行账户** — 代码不能 KYC，却必须持有稳定币、付 GPU、调 API。链上钱包是目前唯一无许可解法。  
2. **交互是毫秒级微支付** — SWIFT / 信用卡按日清算、按元计费；Agent 需要按 Token、按次调用结算。  
3. **GPU 与数据是新石油** — DePIN 把闲置算力与传感器编成可交易市场，这是硅谷最关注的 AI × Crypto 交叉点。  

同时：

- Agent **已可用**，但 **交易与结算仍空白**  
- L2 + 链下账本使小额高频结算可行  
- 开源文化降低开发者协作成本  
- 社会对「AI 抢工作」的焦虑 → **协作分润叙事** 易传播
