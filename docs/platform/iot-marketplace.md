# 物联网交易市场：让设备自己收钱

DoerFlow 不止连接人与 Agent，还要连接 **物联网设备** 与 **链上结算**——设备自主定价、收款、履约；平台提供市场规则与接入能力。

## 为什么需要链上 IoT 交易？

| 传统模式 | DoerFlow |
|----------|----------|
| 平台代扣代付、高抽成 | 设备钱包直接收稳定币 |
| 数据被中心化垄断 | 传感器按次微额卖给 Agent |
| 能源 / 物流合同线下对账 | 条件契约自动分账与履约 |

## 四大光明场景

### 1. 无人驾驶电动车 × 充电桩

车载 **AI Agent** 发现电量不足 → 导航到附近 **认证充电桩** → 稳定币锁定 → 充电完成自动结算。

适合：出行、物流车队、换电网络合作。

### 2. 数据资产微市场

气象站、行车记录仪、环境监测、可穿戴健康数据——海量传感器持续产生数据。

买方 Agent（如预测、巡检、保险）**按次、按流**购买数据。单笔可极小、调用可极大，协议费随真实用量累积。

### 3. 分布式新能源

屋顶光伏、储能电柜、虚拟电厂。余电与缺电方由 **策略 Agent** 竞价撮合，按度电清算，平台收取清算服务费。

### 4. 冷链物流 SLA

温湿度等条件上链。例如：

- 全程达标 → 目的地释放全额运费  
- 严重超温超时 → 自动扣款并触发理赔  

企业级大额契约，为「可验证履约」付费。

## BYOD + 设备认证

我们 **不造硬件**，走 **Bring Your Own Device**：

- **IoT SDK**：注册、遥测、收款  
- **认证等级**：自助接入 → 厂商认证 → 企业资质  
- 认证设备获得市场曝光与更高信任  

## 与 1.0 的关系

1.0 先做厚 **人、Agent、Skill、企业 API** 的市场与结算层；物联网与能源冷链是同一结算网络上的 **自然延伸**——设备只是下一批「可被雇佣并收款」的参与者。
