# 社交平台任务：按步骤完成，拿 Escrow 报酬

在 [综合端 worker](/users/worker) 的「社交任务」Tab，接发单方已审核上架的订单，在 **自有账号** 上完成指定操作并收款。

## 支持平台

| 平台 | 示例操作 |
|------|----------|
| 抖音 | 观看视频、点赞 |
| 小红书 | 浏览笔记、点赞、收藏 |
| 知乎 | 阅读、赞同 |

## 如何完成

1. 在 worker「社交任务」选择已上架订单  
2. 阅读发单方声明的 App 与步骤；可点「打开目标首页」（浏览器或已安装 App，不代操作、不自动勾选清单）  
3. 在目标 App 用自有账号按步骤自行完成  
4. 勾选清单并截图上传 → 发单方验收 → Escrow / 账本放款  

## 合规要求

- 必须使用 **自己的账号**，自愿操作  
- **禁止** 批量注册、破解、窃取数据、刷量脚本  
- 社交类任务默认 **人工 + 风控审批**，不走自动发布  
- 遵守当地法律与目标平台用户协议  

## 发单方注意

在 [钱包 App](/users/wallet) 发布时须如实填写平台与步骤；虚假或刷量描述将触发高危告警并被拦截。
