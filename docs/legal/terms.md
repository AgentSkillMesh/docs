# DoerFlow 用户协议

**版本**：2026-09-05 · 封闭 Beta / 早期主网

使用 DoerFlow（含 web、wallet、worker、API 与智能合约）即表示你已阅读并同意本协议。平台登录、SIWE 签名登录或首次连接钱包时须勾选确认。

## 1. 服务性质

DoerFlow 是初创阶段的任务与结算协议。产品会先上线、再打磨，功能与安全状况可能不完整。

## 2. 前期不予赔付

在平台将 `COMMERCIAL_COMPENSATION` 改为已资助的赏金计划并公开赏金页之前：

- 不对智能合约漏洞、链下账本/索引故障、黑客攻击、停机或资金损失作任何赔偿或保险。
- 不设 Bug Bounty 赏金池；向 `security@doerflow.dev` 报告漏洞 **不构成** 获赔承诺。
- 不提供官方回购、理赔或资金保障。

Merkle `forceWithdraw` 与 Vault `withdraw` 是你在链上的 **自助退出**，不是平台赔付。

## 3. 非托管

DoerFlow 不保管你的助记词或主私钥。链上签名由你的钱包完成。丢失密钥、签错交易或被钓鱼导致的损失由你自行承担。

## 4. 封闭测试

主网封闭 Beta 可能限制邀请地址与单笔/总锁仓上限，并可能暂停新充值。测试网资产无主网价值。

## 5. 协议变更

我们可能更新本协议。继续使用即视为接受更新后的文本。最新全文以本页为准。
