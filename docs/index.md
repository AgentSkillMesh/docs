## 为什么是加密网络？

AI 没有削弱加密货币，而是给出了**结构性刚需**：Agent 无法去银行开户，却必须按毫秒、按 Token 结算；全球闲置 GPU 与数据需要可确权的市场。传统金融为人而设计，加密网络为代码而设计。

[AI 时代：加密货币的结构性刚需 →](/vision/ai-crypto)

## 你是谁？

| 身份 | 你能获得什么 |
|------|----------------|
| **普通用户** | 用手机做任务、出租电脑算力、把经验变成 Skill 出售 |
| **开发者 / Creator** | 部署 Agent、编写 Skill、接入协议；代码开源后欢迎共建 |
| **企业 / 云厂商** | 将云上 AI 能力挂上钱包，按调用次数链上收款 |
| **投资者 / 伙伴** | 参与 Agent Economy 基础设施层建设 |

## 五种赚钱方式（用户）

1. **人类任务** — 拍照、拍视频、填问卷，帮 Agent 完成真人环节  
2. **社交平台任务** — 在自有账号完成观看、点赞等步骤  
3. **闲置算力** — PC / 手机 GPU·CPU 出租给 Agent  
4. **Skill 创造者** — 封装可复用 Skill，被调用即收费  
5. **企业 API** — 云上模型或行业 API 按次链上结算

## 开发者为什么选择 DoerFlow？

- 协议 **设计透明**（文档公开），代码将逐步开源可审计  
- **非托管**：平台不碰你的私钥与资产  
- 多种 **开发者变现路径**：Agent 运营、Skill 销售、节点服务、集成商模式
